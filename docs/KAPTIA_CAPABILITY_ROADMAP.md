# Kaptia 專屬模型與本機文件能力路線圖

## 目標與誠實界線
Kaptia 以本機 Qwen 為基礎，逐步建立繁體中文專屬行為、可檢索的專案知識，以及能呼叫本機文件工具的工作流程。不能宣稱目前已達到 Claude 5.0 或其他商用前沿模型的同等能力；必須用固定基準測試衡量。不能複製其他模型的私有權重、訓練語料或隱藏推理。

## 分層架構
1. 基礎語言模型：Qwen 作為可替換的本機推理引擎。
2. 專屬行為微調：只用有權使用、去識別化、品質審核的資料進行 LoRA/QLoRA。
3. 本機知識檢索（RAG）：匯入使用者指定文件，切片、建立索引，回答時保留來源位置；更新知識不必重新訓練。
4. 工具路由：模型產生受限工具請求 JSON；程式驗證 schema、路徑、檔案類型、操作範圍和輸出位置後，才呼叫允許清單中的工具。
5. 交付驗證：重新開啟輸出檔，檢查頁數、投影片數、檔案大小和基本結構，回報實際結果。

## 初始文件工具範圍
規劃加入的本機工具包括：檢查 PPTX 文字與表格、替換簡報中的指定文字並另存新檔、建立簡單可編輯 PowerPoint、抽取 PDF 可選取文字、合併 PDF、拆分 PDF。這不是完整 Office 編輯器；任意版面精準保真、複雜動畫、SmartArt、完整圖表編輯、PDF 文字原位改寫、OCR、數位簽章和受保護檔案解鎖需要額外能力。

## 安全與可靠性
- 只處理使用者明確指定的檔案，不遞迴掃描私人資料夾。
- 不執行文件巨集、嵌入腳本或外部連結。
- 不繞過密碼、DRM 或存取控制。
- PDF 抽取不到文字時提示可能是掃描件；不能假裝 OCR 成功。
- 原檔預設不覆寫；工具須有成功、失敗、損毀檔案和不支援格式測試。
- 模型自我審核不是獨立事實查核。

## 訓練與評估
起始資料只是示範，不能證明達到前沿模型能力。建立互不重疊的訓練/驗收資料；微調前後使用相同題目比較。指標包括繁體中文指令遵循、長上下文一致性、工具選擇、結構化輸出有效率、越權請求拒絕、文件引用正確率、簡報大綱品質和 PDF 操作正確率。保留模型版本、資料版本、訓練設定、日誌與指標。

iPhone Safari 不應直接載入 Windows 的 PEFT adapter。手機端需另行轉換成瀏覽器可用格式，並實測記憶體、速度、離線快取與相容性。

## 驗收階段
A：文件工具單獨執行、輸出可讀回。
B：安全工具路由，只允許白名單工具。
C：RAG 文件匯入、切片、檢索和來源標記。
D：擴大微調資料並跑獨立驗收集。
E：手機和桌面使用合適模型，測試斷網、重啟、快取與錯誤。
