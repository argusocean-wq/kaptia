Kaptia 是面向 Windows 的本機文字 AI 助理。從這個網站了解產品並下載啟動器；本機起步模型訓練完成後，對話由你的電腦執行，而不是在這個網頁裡聊天。

下載 Windows 版 (.exe) ↓ 查看 GitHub 專案 ↗

Windows 10/11 · 初次設定需要網路與數 GB 儲存空間。安裝程式由 GitHub Actions 建置並發布；首次啟動會從隨機初始化訓練 Kaptia 起步模型，不會下載成品模型。

GET STARTED

從下載到本機對話

STEP 01
下載 .exe

從 GitHub Releases 取得 Windows 啟動器。請只執行你信任且已核對來源的版本。

STEP 02
安裝依賴與起步訓練

首次啟動需要網路、磁碟空間與等待時間。本機模型權重會保存於本機供後續載入。

STEP 03
啟動本機模型

完成設定後，從桌面啟動 Kaptia。之後是否能完全離線，取決於模型與必要依賴是否已完整下載。

SYSTEM REQUIREMENTS

開始前請確認

作業系統

Windows 10 或 Windows 11（64 位元）。目前此安裝流程不是 iPhone/iPad 安裝程式。

網路與儲存空間

首次設定需下載 Python 套件並執行起步訓練。請預留足夠磁碟空間；訓練速度取決於 CPU/GPU。

硬體

可使用 CPU 執行但可能較慢；相容的 NVIDIA GPU 可改善部分工作負載的速度與記憶體配置。

隱私與限制

本機推論不等於所有安裝步驟都離線。下載來源、模型授權、遙測與外部連線狀態應以實際發布版本說明為準。
